Flowdesk — AI Support Triage (Portfolio Demo)

Files: flowdesk_ai_triage.html (self-contained app)

How to run:
1. Open flowdesk_ai_triage.html in a modern browser, or deploy it as index.html in a separate static site project.
2. The app requires no build command, dependencies, backend, API keys, or environment variables.
3. Use the sidebar to move between Overview, Support Inbox, Automations, and Analytics.
4. Add a sample ticket, inspect the generated triage, edit/copy a suggested reply, mark tickets resolved, and export data to CSV.

Transparency:
This is a portfolio prototype using sample data, local deterministic rules, and browser localStorage. It does not call an external AI model, send emails/messages, or process real customer records. The UI labels this clearly.
